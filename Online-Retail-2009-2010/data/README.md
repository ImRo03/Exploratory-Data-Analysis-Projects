# Dataset

This project uses the 2009-2010 sheet from Online Retail II.

Place the file here before running the notebook:

`Year_2009-2010.csv`

The dataset can be downloaded from the [UCI Machine Learning Repository — Online Retail II](https://archive.ics.uci.edu/dataset/502/online+retail+ii).

The CSV is large (about 47 MB). The connected GitHub upload action available to me can add text files and notebooks but cannot transfer this local binary dataset file directly, so the CSV still needs to be added through GitHub Desktop or the Git command line.
