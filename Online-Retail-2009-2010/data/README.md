# Dataset

This project uses the 2009-2010 sheet from Online Retail II.

Upload this file into this folder:

`Year_2009-2010.csv.zip`

The notebook reads the CSV from the ZIP directly with Pandas, so there is no need to extract it first. Run Jupyter from the `Online-Retail-2009-2010` project folder.

The dataset can also be downloaded from the [UCI Machine Learning Repository — Online Retail II](https://archive.ics.uci.edu/dataset/502/online+retail+ii).
